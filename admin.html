Edit any text, image, video, link, menu item, social link or Instagram post. Add, remove, reorder (arrows or drag) and hide items. Press SAVE (top right, or Ctrl/⌘ + S): your changes are saved to GitHub and the live website updates in about 1–2 minutes. PREVIEW shows unsaved changes to you only.
